# Translation Automation

A personal tool for discovering English-to-Japanese
translation projects and supporting AI-assisted translation.

## Planned Features

- Search translation projects using authorized APIs
- Filter projects by language, budget and requirements
- Translate English text into Japanese using DeepL
- Review translations using OpenAI
- Generate translation files for human review

## Tech Stack

- Python
- Freelancer.com API
- DeepL API
- OpenAI API

## Status

Under development.

AI translation will only be used when permitted by
the client and applicable platform policies.
